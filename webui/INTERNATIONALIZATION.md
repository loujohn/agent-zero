# Agent Zero 国际化系统

本文档描述了Agent Zero项目的国际化(i18n)实现，遵循Linus Torvalds的设计原则：简单、实用、零破坏性。

## 设计原则

### 1. 好品味 (Good Taste)
- 使用简单的key-value映射，没有复杂的嵌套结构
- 统一的翻译函数 `t(key, fallback, params)`
- 消除前端和后端文本处理的特殊情况

### 2. 不破坏用户空间 (Never Break Userspace)
- 默认保持英文，现有用户完全不受影响
- 翻译函数找不到翻译时返回原文或fallback
- 渐进式替换，零破坏性升级

### 3. 实用主义
- 解决真实的中文用户需求
- 最小可行的国际化方案
- 不追求理论完美，专注实际效果

## 核心组件

### 1. 翻译系统核心 (`webui/js/i18n.js`)

```javascript
// 基本用法
window.t('common.save')           // 返回 "保存" (中文) 或 "Save" (英文)
window.t('common.save', '保存')   // 使用fallback
window.t('user.greeting', 'Hello {name}!', {name: 'John'}) // 参数替换
```

### 2. HTML标记支持

```html
<!-- 文本翻译 -->
<span data-i18n="common.save">Save</span>

<!-- 占位符翻译 -->
<input data-i18n-placeholder="chat.input.placeholder" placeholder="Type here...">

<!-- 标题翻译 -->
<button data-i18n-title="common.save" title="Save">保存</button>
```

### 3. 后端设置集成

语言设置存储在后端设置系统中，通过 `ui_language` 字段管理。

## 支持的语言

- `en-US`: English (默认)
- `zh-CN`: 简体中文

## 添加新翻译

### 1. 在 `webui/js/i18n.js` 中添加翻译键

```javascript
// 英文翻译
this.translations['en-US'] = {
    'your.new.key': 'Your English Text',
    // ...
};

// 中文翻译  
this.translations['zh-CN'] = {
    'your.new.key': '您的中文文本',
    // ...
};
```

### 2. 在HTML中使用

```html
<span data-i18n="your.new.key">Your English Text</span>
```

## 翻译键命名约定

- 使用点分隔的层级结构
- 按功能模块分组
- 示例：
  - `common.*` - 通用按钮和文本
  - `settings.*` - 设置页面
  - `chat.*` - 聊天界面
  - `login.*` - 登录页面
  - `scheduler.*` - 任务调度器

## 语言切换

### 前端切换
```javascript
window.i18n.setLanguage('zh-CN'); // 切换到中文
window.i18n.setLanguage('en-US'); // 切换到英文
```

### 后端同步
语言设置会自动同步到后端设置系统，确保用户偏好持久化。

## 扩展新语言

1. 在 `i18n.js` 的 `initTranslations()` 方法中添加新语言翻译
2. 在 `getAvailableLanguages()` 方法中添加语言选项
3. 在后端设置的语言选择器中添加新选项

## 最佳实践

1. **保持简单**: 不要过度设计，使用最直接的翻译方式
2. **渐进式**: 优先翻译用户最常见的文本
3. **一致性**: 相同概念使用相同的翻译
4. **测试**: 每次添加翻译后测试语言切换功能
5. **Fallback**: 始终提供英文fallback，确保系统稳定

## 故障排除

### 翻译不显示
1. 检查翻译键是否正确
2. 确认HTML标记是否正确
3. 查看浏览器控制台是否有错误

### 语言切换不生效
1. 检查 `i18n.js` 是否正确加载
2. 确认设置页面的语言字段是否正确配置
3. 查看网络请求是否成功同步到后端

### 新翻译不生效
1. 清除浏览器缓存
2. 检查翻译键的拼写
3. 确认页面重新加载后调用了 `updatePageTexts()`

## 技术实现细节

- **存储**: 使用 localStorage 和后端设置双重存储
- **同步**: 前端变更自动同步到后端
- **加载**: 页面加载时从后端获取用户语言偏好
- **更新**: 语言切换时自动更新所有标记的元素
- **事件**: 提供 `language-changed` 事件供其他组件监听

这个国际化系统体现了"好品味"的设计：简单、直接、可靠，没有不必要的复杂性。
